## Project Description

The EduSkill Marketplace System (EMS) is a web-based platform that allows training providers to register and list courses, learners to enrol in courses, and Admin officers to approve provider registrations.

## Technologies Used

* HTML5
* CSS3
* Bootstrap
* JavaScript
* PHP
* MySQL
* XAMPP

## Installation / Setup

1. Install XAMPP.
2. Clone this repository.
3. Move the project folder to `xampp/htdocs`.
4. Start Apache and MySQL in XAMPP.
5. Create a database named `ems_db`.
6. Import the provided SQL file using phpMyAdmin.
7. Open `http://localhost/eduskill-marketplace/` in a browser.
